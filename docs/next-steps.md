# Product roadmap

## Available now

- A guided **Connect → Choose → Review → Result** workflow with one main action per stage. Connecting by address starts the scan once that TV is authorized.
- Automatic suggestions for **Keep my smart TV**, **Reduce TCL reporting** and **HDMI & live TV**. Choosing a goal only prepares changes; application requires review.
- Individual app/settings controls and evidence under **Advanced**. Protected, unknown and unsupported versions cannot be disabled.
- Direct **Undo these changes** from a result, with a fresh scan and restoration preview. **History** provides earlier journals.
- Optional functional checks and private report downloads tied to their source apply journal.
- A manual **Use TV without an account** guide for official Basic TV setup. It explains capability limits and factory-reset data loss before revealing instructions. The app never performs the reset.

Basic TV is for HDMI, tuner/live TV and limited preinstalled apps. Converting an existing full Google TV setup requires a factory reset that erases accounts, installed apps, app data and settings. A recovery journal cannot undo that loss. After the owner completes setup, the app requires a fresh complete scan of the same TV before applying or restoring saved previews.

## Planned improvements

- Improve the guided workflow through user feedback and accessibility checks.
- Expand supported firmware profiles only after verifying package versions, retained functions and exact restoration.
- Consider additional privacy controls only when their prior state, effect, recovery and persistence can be verified.

Microphones, Wi-Fi and Bluetooth currently have manual guidance. Automated sensor/radio blocking, root, firmware flashing and replacement operating systems are unavailable. The HDMI profile does not disconnect networking, and the two TCL reporting flags do not establish that every reporting path stopped.

## Contributing

Run the core test suite and use synthetic fixtures for browser checks. Do not infer real-TV compatibility from a simulated run. Keep personal inventories, identifiers, launch tokens, APKs, traffic captures, raw logs, research notes and recovery journals outside public commits and release artifacts.
